## Proyectos destacados

**Nova Smart**
- Fundé, junto al equipo inicial, el área de Sistemas de la empresa. Diseño y construyo la arquitectura de base de datos que sostiene todos los productos internos.
- **Sitio web corporativo:** landing page con catálogo de productos y servicios de Fibra Óptica FTTH/HFC, canal de ventas, coordinación de instalaciones y bolsa de trabajo. Stack: Astro + TypeScript.
- **App móvil empresarial:** sistema con roles y permisos granulares por módulo y área; ventas, instalaciones, almacén, auditorías con firma digital, caja, mantenimiento de flota vehicular, rastreo de productos y asistencia con reconocimiento facial. Stack: Expo/React Native + Supabase.
- **Bandeja de WhatsApp:** panel con dashboard de métricas, chat en tiempo real y editor de plantillas para el bot, conectado a Supabase Edge Functions.
- **Automatización de WhatsApp:** bot construido sobre la API de Meta (WhatsApp Business Cloud API) con Python y TypeScript.

**GOYO MOTORS** — ERP
- Lideré la digitalización integral de la empresa, diseñando desde cero un ERP multi-sucursal con Firestore independiente por sede.
- Módulo de inventario con control de stock por lotes bajo lógica FIFO y transacciones atómicas.
- Módulos de productos, ingresos, ventas, cotizaciones, créditos, devoluciones, clientes, proveedores, empleados, caja y auditoría.
- Generación de PDFs, exportación a Excel y dashboard analítico con Recharts.
- Stack: Next.js + Firebase.

**Ayni.pe**
- Marketplace tipo Uber que conecta clientes con profesionales y freelancers verificados cerca de su ubicación.
- Doble modo cliente/profesional, geolocalización en tiempo real y verificación de prestadores de servicio.
- Desarrollado para la feria comercial de la carrera de Administración de la UNTELS.
- Stack: Expo/React Native + Firebase.

**SIMATV** — Aplicación IPTV para Android TV y Smart TV
- Co-desarrollo para la empresa de telecomunicaciones SIMA: streaming de canales en vivo con alta disponibilidad.
- UI/UX nativa para pantallas grandes, con navegación controlada exclusivamente por control remoto (D-pad).
- Integración y optimización de protocolos HLS/DASH, reduciendo la latencia y el tiempo de zapping.
- Arquitectura para gestión de listas de canales y sincronización de la Guía Electrónica de Programación (EPG) en tiempo real.
- Stack: Kotlin nativo.

**RESCUEMAL** — App móvil de rescate animal
- Aplicación orientada a la problemática de animales en situación de calle, alineada con los ODS.
- Arquitectura híbrida Kotlin/Java, integración con Google Maps Platform para geolocalización y trazado de rutas de rescate.
- Infraestructura de datos en Firebase: Cloud Firestore para sincronización en tiempo real y Firebase Storage para evidencias fotográficas.
- Digitalicé el proceso de rescate y adopción, sustituyendo métodos informales por una plataforma centralizada.

**Consultas Perú** — Herramienta de consulta DNI/RUC
- App de búsqueda de personas mediante DNI o RUC: devuelve todos los datos asociados al documento.
- Guarda cada búsqueda en caché (Firestore), quedando registrada en la base de datos para consultas futuras.
- Stack: Next.js + Vercel + Firebase, integración con Factiliza API.

**FormBlaster** — Masificador de respuestas para Google Forms
- Analiza el payload del formulario para detectar sus campos automáticamente.
- Permite configurar cada campo con un valor fijo o aleatorio entre varias opciones.
- Envía las respuestas en modo ráfaga (con delay configurable) o programado (cada N minutos).
- Stack: Next.js + TypeScript, desplegado en Vercel.

**WhatsApp Line Extractor**
- Extensión de Chrome que detecta automáticamente las fotos abiertas en WhatsApp Web.
- Aplica OCR con Tesseract.js para leer el campo "Línea" y copia el número extraído al portapapeles.
- Historial de las últimas 100 lecturas. Desarrollada para agilizar una tarea operativa diaria.

**Herramienta CLI para Git & GitHub**
- CLI multiplataforma en Node.js que automatiza todo el ciclo de vida de un repositorio (init, staging, commits, sync).
- Flujos interactivos en terminal con readline-sync y manejo de procesos del sistema (child_process).
- Integración con la API/CLI de GitHub (gh) para autenticación y aprovisionamiento de repositorios en la nube.
- Alias contextuales (`gracias-edward` / `actualiza-edward`) para flujos de quick-push. Publicado como paquete npm.

**L'Elixir** — Catálogo virtual
- Catálogo virtual publicitario para la venta de perfumes, orientado a conversión.
- Construido con Astro para una carga rápida y una experiencia de navegación ligera.

**ControlPorts**
- CLI multiplataforma para Windows que lista, busca e inspecciona procesos ocupando puertos.
- Permite terminarlos por puerto o PID directamente desde la terminal, con menú interactivo. Publicado como paquete npm.

**FastData**
- Extensión de Chrome que rellena formularios web con datos ficticios realistas para 10 países de Latinoamérica y España/Portugal.
- Detección inteligente de campos y soporte para React/Vue.
